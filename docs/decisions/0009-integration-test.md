# 0009 結合テスト

## 背景

- Spring Batch の構成や起動引数の受け渡しなど、全体を通して正しくつながっているかを、実の MySQL や LocalStack を使う結合テストで確かめたい（利用者の要望、2026-10-20）
- 結合テストを追加する社内スキルがすでにある（利用者、2026-10-20）

## 決定

本スキルでは結合テストの書き方を定めない。結合テストは、結合テストを追加する `add-` スキルで作るよう SKILL.md で示すだけにする。社内スキルと決まりが二重になり、食い違うのを避けるため。

一度は本スキルに結合テストの参照資料（`jvm-test-suite` で `build` と分ける、Testcontainers、`SpringApplication.run` で本番と同じ起動引数を渡す）を加え、実の MySQL 8.4 で動くことまで確かめたが、上の理由で取り下げた（コミット 1d047c0 を参照）。
