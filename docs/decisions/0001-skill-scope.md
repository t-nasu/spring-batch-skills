# 0001 スキルはチーム固有の決まりだけを扱う

## 背景

利用するエージェント（Codex の gpt-6-sol、Claude Code の Opus 5）は、Spring Batch や MyBatis の一般的な書き方をすでに知っている。一般論を教えるスキルは効き目が薄く、コンテキストを無駄に使う。

## 決定

スキルには、エージェントが自力では知り得ないこと（層構成の決まり、Batch か素の Boot かの判断基準、ネットなしで使う版、出力の揃え方）だけを書く。決まりの理由や経緯はこの `docs/decisions/` に置き、スキルには含めない。

効き目はスキルの有無で出力を比べて確かめる（`eval/`）。差が出なければ、そこで打ち切る。
