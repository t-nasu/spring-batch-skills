# 0004 命名・SQL・パッケージ名

## 決定と理由

- **ユースケースは `〇〇UseCase` とし、`〇〇Service` という名は使わない。** 「Service」という名を許すと、開発者が何でもサービスに入れてしまう悪い習慣がつくため。
- **MyBatis の SQL はすべて XML に書く。** アノテーション SQL と混在させない。
- **Mapper はテーブル形の DTO を返し、ドメインのエンティティを resultMap に直接対応させない。** テーブル構造の変更がドメインに波及するのを防ぐため。
- **最上位の層のパッケージ名は `presentation` ではなく `batch` とする。** バッチの起動口であることを名前で示すため。
